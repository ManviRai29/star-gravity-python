# ⭐ Star Gravity Simulation

A simple interactive Python animation that simulates a **gravity-like attraction between stars and the mouse cursor**.

Stars are generated at random positions on the screen and continuously move toward the mouse cursor when it comes within their attraction range, creating a visually engaging space-like effect.

## 🚀 Features

* ⭐ Random star generation
* 🖱️ Real-time mouse interaction
* 🌌 Gravity-like attraction effect
* 🎞️ Smooth continuous animation
* 🔄 Dynamic star movement
* 💻 Lightweight and easy to run

## ⚙️ How It Works

The simulation follows a simple process:

1. Stars are generated at random positions on the screen.
2. The program continuously tracks the mouse cursor.
3. When the cursor comes within the attraction range of a star, the star moves toward it.
4. The movement is updated continuously to create a gravity-like animation.
5. Moving the mouse around the screen changes the direction of the stars in real time.

## ▶️ How to Run

### 1. Download or Clone the Project

Download `mousegravity.py` or clone the repository:

```bash
git clone <repository-url>
cd Star-Gravity-Simulation
```

### 2. Make Sure Python Is Installed

Check your Python version:

```bash
python --version
```

or:

```bash
python3 --version
```

### 3. Run the Program

```bash
python mousegravity.py
```

If your system uses `python3`:

```bash
python3 mousegravity.py
```

### 4. Interact With the Simulation

Move your mouse around the window and watch the stars get attracted toward the cursor.
